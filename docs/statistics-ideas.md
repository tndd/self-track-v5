# 統計の試験機能と今後の案

グラフを増やす前に「自分について、次に何を知りたいか」を起点にする。カレンダーはその日の事実、統計は繰り返す傾向と発見を担う。

## 実装した試験機能

1. **タグの前後の変化**：タグを記録した時点にそろえ、直前・1時間後・3時間後・6時間後・翌日の経過を比較する。立ち上がり、持続、反動を探す。観測がない時間は空白にし、同じ時間帯・開始時の体調が近い日を比較相手にする。同タグの起点は一日最初の投稿にまとめる。グラフの時点は等間隔に配置し、時間の実際の長さとは一致しない。
2. **条件による違い**：全体平均では埋もれる「つらい日に限る」「夜に限る」「別のタグと同時のとき」を探す。低め／平均2.5以上、同時タグ上位6種を表示。両側5日未満は差を出さない。条件間の相互作用検定は行わない。
3. **発見の受信箱**：統計の入口には、探索期間だけで選んだ候補を最大2件だけ表示する。差の大きさ、比較した日数、別期間でも続いたか、元の記録への入口を付ける。保存・保留・非表示で整理できる。前半65%と後半35%を分け、方向の再現と比較日数を表示する。候補探索の多重性を補正した検定ではないため、統計的な確証とは呼ばない。独立したAIモデルによる発見ではなく、記録を条件別に集計する試験機能。

## 実装した追加の比較と、未実装の候補

| 項目 | 知りたいこと | 計算上の条件 |
| --- | --- | --- |
| 回復までの時間（実装） | 低調になってから、普段の状態に戻るまでどれくらいか | 体調1〜2の投稿から次の3以上までの観測区間と未確認を区別。平均回復時間は算出しない |
| 安定度（実装） | 同じ平均3でも、ずっと3なのか1と5を往復したのか | 変化幅と隣接観測の変化を分ける。記録数や間隔の偏りも表示 |
| 過ごしやすかった時間 | 自分で決めた体調以上で過ごせた時間が増えているか | 記録回数を時間に読み替えない。十分な観測がある期間だけ範囲で推定し、未観測時間も併記 |
| 量の曲がり角 | 数量・強度と体調の関係は直線か、頭打ちか | 同じタグ内で数値の意味・単位をそろえる。薬の増減の推奨はしない |
| 順序と連続（実装） | A→BとB→A、単発と連日のときで違うか | 発生前の体調、間隔、重なる出来事を考慮。単純な因果と呼ばない |
| 傾向の変わり目 | 以前の自分と、最近の自分で何が変わったか | 記録習慣の変化と体調の変化を分ける。古い関係が再現しなくなったことも示す |
| 似た日の続き（実装） | 過去の似た状態のあと、自分はどうなったか | 候補は過去のみ。近い記録と実際の後日を示し、予測の確実性を誇張しない |

## 集計の範囲と注意点

- 投稿の時刻を使う三つの分析（タグの前後、回復、安定度）には実際に記録された投稿だけを使用。一日の総括を選んでも、時刻付きの投稿の代わりにはしない。
- 日別の条件・順序・似た日と発見の受信箱は、選んだ「投稿の平均／一日の総括」を使用。日別比較の母数は日数で数える。
- 時刻付きの投稿は利用者と試用データを分離して取得し、コメントと数量は分析用 API に含めない。対象期間が2万件を超える場合は範囲を縮める案内を返し、一部だけで集計しない。
- 試用データの規則的なタグの組合せで出る数値は、機能の動作確認用。実生活の予測性能は示さない。

## 今後の検討と原則

- 発見用の古い期間と、確認用の新しい期間を分離する。未来のデータを過去の予測に混ぜない。
- 多数のタグ・時間差・条件を試すと偶然の差が増える。検定をする場合は多重比較を扱い、同じ候補を繰り返し探索した影響も管理する。
- 日々の記録は独立ではない。日・週のまとまりを保った再標本化などを検討し、投稿件数を独立標本数として水増ししない。
- 欠測と未選択を区別する。未選択の体調3は既存仕様だが、記録のない時間は3ではない。
- 体調が悪いから休憩・服薬した可能性がある。前後関係や調整を加えても、観察記録だけで因果を確定しない。
- ダミーデータは表示・計算・既知のパターンを検出できるかの試験に使う。実生活での予測性能の根拠にはしない。
- 次に必要な記録を一つだけ提案する案もあるが、頻繁な通知や入力項目の追加を前提にしない。
