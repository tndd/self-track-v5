# v17 Apple風の設定ダイアログの位置修正

## 原因と変更

Apple風のスマホ用CSSが、共通ダイアログの中央配置を画面下基準に切り替えていた。デザイン設定を開いたままUIをApple風に変えると、位置と平行移動の指定が同時に変化し、切り替え中にダイアログが画面上へはみ出した。Apple風は素材と余白だけを変更し、配置の基準は共通ダイアログに統一した。

## ブラウザーで確認した操作

- 390px幅：デザイン実験を開いたまま標準→Apple風→標準→Apple風と切り替え、各時点で設定画面が表示範囲内に収まることを確認。切り替え前は上端が約−131pxになったが、修正後は切り替え直後も画面内。
- 390px幅：「この配置で試す」で閉じ、Apple風のまま設定を再度開けることを確認。
- 320px幅：左8px、右8px、上10px、下10pxの余白を確認。内容が長い場合はダイアログ内でスクロールできる。
- 1100px幅：設定が中央に配置され、左右・上下ともに画面内に収まることを確認。

`pnpm build` 成功。試験用のページはソースから削除して公開アーカイブに含めない。
