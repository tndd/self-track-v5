# v16 統計の試験機能の確認

## 実装範囲

- 統計タブの冒頭に、前半で候補を選び後半で傾向を確認する「発見の受信箱」を追加。最大2件、保存・保留・非表示と解除ができる。常に同じ日に付くタグは別候補として並べない。
- 下のテーマ選択から「タグの前後」「条件による違い」「回復まで」「安定度」「順序と連続」「似た日の続き」を切り替える。各分析に日数・欠測・根拠の記録を示す。
- 従来の日単位の比較とタグ同士の相関は折りたたみ欄に残した。カレンダーは日ごとの概要を担当する。
- 詳細用の時刻付き記録は利用者・試用領域・期間で絞り、スコアとタグだけを取得。2万件を超える期間はエラーを表示する。

## 手法と読み方

- 未選択の投稿スコアは既存仕様の3として扱う。投稿のない時間には値を付けない。時間窓は実際に記録された最寄りの投稿だけを採用する。
- 前後の起点は同じタグを記録した日の最初の投稿。体調と6時間帯が近いタグなし日を比較し、同じ比較日を使っても日数は増やさない。窓ごとに対象日が違う。
- 回復は低調な投稿から次の3以上の投稿までの区間。空白が長い例と期間末の例は未確認に分ける。安定度は最低・最高と平均、3時間以内の隣接投稿の差を別々に示す。
- 順序は各タグの最初の記録時刻で区分し、同時刻は除外する。連日は前日に投稿がある日のみ比較。似た日の候補とその翌日は、対象日より過去の記録に限る。
- 発見の受信箱は観測日を65%と35%の期間に分け、最初の期間で候補を固定する。後半の結果で入れ替えない。これは探索の手がかりで、多重比較を補正した検定、個人の予測モデル、因果効果の推定ではない。
