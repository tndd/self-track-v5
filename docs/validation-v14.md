# v14 統計の再設計・検証記録

## 変更内容

- 統計タブから一日の時間軸と簡易サマリーの重複を除去。日内の記録は記録画面、日々の波と簡易集計はカレンダー、タグの詳細比較は統計へ分担。
- 同じ日のタグと体調の比較、翌日・2日後・3日後・7日後の変化差、タグ同士のφ相関と組み合わせ別の平均を追加。
- 1日を等重みで扱い、時間差比較は起点の体調を四捨五入した層で構成をそろえる。欠測・期間外・未来日を補完しない。
- 両群5日以上で変化差を表示。比較日数・欠測・対応する比較日がない日数を明示。四分位範囲は観測された変化の分布として表示。
- 期間・体調の基準を切り替えても選んだタグを保持。消えたタグに限り候補に切り替える。
