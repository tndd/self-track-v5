# 配備メモ

## 現行の稼働先

Cloudflare Workers互換のVinextアプリをSitesで配備し、D1とSitesが付与する利用者認証ヘッダーを利用する。既存のプロジェクトIDと所有者専用設定を継続する。ソースのGitHubへの登録で、DBの内容や認証情報は移動しない。

公開手順はSitesスキルに従い、ビルド・ソース保存・マイグレーション適用・配備結果の確認を行う。ローカルの試験用DBは含めない。

## GitHub

対象は`https://github.com/tndd/self-track-v5`。アプリのソース、依存ロック、DB移行、テスト、文書を格納する。公開リポジトリのため、`.env`、`.wrangler`、ローカルDB、資格情報、実際の体調記録を含めない。

## Vercel（未配備）

2026-09-18（日本時間）に接続済みVercelのチーム・プロジェクト一覧を取得できた。公開ツールは利用できず、呼び出しに対して`Tool deploy_to_vercel not found`が返った。

加えて、現行コードには次の移行条件がある。単にGitHubからインポートしただけでは稼働しない。

1. `cloudflare:workers`のD1バインディングをVercelで利用できる永続DBへ置換する。スキーマ、データの移行、所有者対応を確認する。
2. Sitesが付与する`oai-authenticated-user-*`はVercelの信頼済み認証情報ではない。Vercel用の認証・セッション検証・所有者制限を実装する。外部から任意に送られる同名ヘッダーを信用しない。
3. Next.js等のVercel向けビルドを用意し、保存・再読込・未認証拒否・他利用者からの分離を実APIで検証する。
4. 既存の記録を移す場合は、移行後の件数・元の記録日時・日別総括を照合してから稼働先を切り替える。

ユーザーがVercelを後回しにしてよいと指定しているため、未認証の代替版やブラウザー保存だけの別アプリを公開しない。現行URLで改修版を使える状態を先に届ける。
