# 検証記録

## 対象・範囲

2026-09-18（日本時間）。新規アプリ「しずく」。PROMPTS/dev.md version 3、DEV_UNIFIED_END 2.0.6を適用。同文書内のWorkbench節を使用（PROMPTS直下に別のWorkbench文書はなし）。

必須能力は source / runtime / dependency / repositoryCommand / localServer / browser / D1。必須境界はローカル計算・型検査・製品ビルド・管理プレビュー内の実ブラウザー操作とD1保存。外部医療データ・AIモデル・別サービスとの連携は不要。

新規作成のため既存製品との差分はない。成果物は要求された記録、タグ付きコメント、履歴検索、疼痛集計、タグの関連分析と、それに必要な非公開保存・編集・エラー処理・CSV出力に対応する。

## 実測

- Sitesスターターを空の専用ディレクトリーへ配置。pnpmロックファイルに従い628パッケージを再利用して復元。
- TypeScript型検査：成功。
- 5件の集計・入力検証テスト：成功。日本時間、欠測、日平均、最大疼痛、タグの等日重み、翌日の連続性、範囲外の拒否を検証。
- 製品Workerビルド：成功。移行SQLは1テーブルと複合主キー・ユーザー/日付の索引。
- 管理プレビュー：実ページへ到達。最初にHTTP上でcrypto.randomUUIDが利用できない問題を検出し、getRandomValuesによるUUIDへ修正。修正後1タップ投稿が成功。
- 実ブラウザー：体調のみ、タグ付きメモと体調の同時投稿、疼痛7の記録、再読み込み後の履歴、言葉での検索、既存記録の追記、疼痛0、独自タグ、変更の保存、集計への反映を確認。
- 初期画面と390px幅の記録・集計画面を画像として視覚確認。長いラベルの折り返し、疼痛選択、スマートフォンのモーダルを確認。
- 日体調2と4の平均3.0、疼痛0と7の最大値7.0、記録の足りないタグで「記録を待っています」、翌日未記録で比較件数0を確認。
- ブラウザー上のWebMCPはmodelContext未提供のため登録・実行検証は unavailable。機能検出で通常操作に影響しない。読取専用のツールのみ実装。

## 境界と制約

管理ブラウザーから内部プレビューへの到達は成功。シェルからそのプレビューへのHTTP到達は別の経路で、失敗（接続不能/タイムアウト）。両者を同一の接続能力と扱わない。

本番URLでのブラウザー検証は管理環境の規約により行わない。公開の成功はSitesの正式な配備結果で確認する。試験データはローカルD1のみで、本番へのシードは含めない。

統計は観察上の単純な関連。因果推論・医学的換算を行わない。ロード・保存の失敗を成功として表示せず、再送用UUIDを保持して重複を防ぐ。
