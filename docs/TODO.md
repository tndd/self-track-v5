# 今後の実装候補

## 疼痛スコアの算出（未実装）

一日の体調、投稿した時々の体調、タグの種類・頻度・時系列などを材料に、日別の疼痛スコアを算出する構想。今回の変更では入力欄と既存の直接入力値の表示を外し、算出処理は実装しない。

実装前に決めること：

- 何を目的変数・基準値とするか。体調5段階を機械的に疼痛0〜10へ換算しない。
- 一日の総括とその時の記録の重み、タグの意味、欠測日の扱い。
- 計算式・バージョン・使用データ・確からしさをあとから確認できる形。
- 実測した疼痛と推定値を区別し、推定を診断と誤認させない表示。

算出式、係数、仮の疼痛値、隠れた自動計算は今回のコードに含めない。
