# self-track-v5 — しずく

体調を少ない操作で残し、その時々の変化と一日全体を分けて振り返る個人用アプリ。

[アプリを開く](https://shizuku-health-journal.tau-s.chatgpt.site)

## 記録の使い分け

| 画面 | 記録するもの | 操作 |
| --- | --- | --- |
| その時の記録 | その瞬間の5段階の体調、タグ、メモ | 体調を選択 → 送信。タグを付けても基本3タップ |
| カレンダー | 一日全体の5段階の総括、コメント | 日付をタップ → ポップアップで評価 → 総括を保存 |
| タグ管理 | グループ、タグ | 追加・所属変更・非表示・再表示 |
| 統計 | タグの前後・条件・回復・安定度・順序・似た日と、日単位の比較 | 期間や分析対象を切り替えて調べる |

- 記録・カレンダー・統計・タグ管理の4タブを画面下に常時表示します。標準レイアウトが初期設定です。
- 体調の選択だけでは保存しません。送信または保存ボタンで確定します。
- 投稿の編集では記録日時と日付を変更しません。更新日時だけを別に保存します。
- 過去への新規投稿は「タグ・日時」から日時を指定できます。時刻を含め日本時間です。
- 履歴は記録画面に統合。40件ずつの自動追加読み込みと、言葉・タグ・日付による検索を利用できます。
- 一日の総括は日付ごとに1件。投稿の平均から自動作成・上書きしません。
- 体調は顔アイコンだけで選択。メモはコンパクトな固定高、頻出タグはカード内で折り返します。タグ・日時を開くと、その下にグループと日時が展開します。
- 履歴は左に体調アイコンと時刻を表示。同じ日の隣り合う投稿が1時間以内なら中心を線でつなぎ、それ以上は線を切って時間差を表示します。体調のみの投稿は空の吹き出しを省きます。
- カレンダーは間隔を空けた丸いマス全体をアイコンと同じ体調色で表示し、月に必要な4〜6週だけ描画。下に選択日の総括・投稿時の平均・投稿数・タグを表示します。
- 一日の時間軸は「その時の記録」の試験レイアウトだけに集約。カレンダーには日別の簡易統計と月の波、統計にはタグの詳細分析を配置します。
- 右上のフラスコの「デザイン実験」から、UI（しずく標準・Apple風・Google風・OpenAI風）と配置（標準・一枚・会話・日めくり）を独立して選べます。各ブランドのデザイン思想を参考にした独自UIで、公式製品や提携を意味しません。配色とは独立し、このブラウザーに保存します。下書きは切り替えても保持。旧ノート・ワークスペースは撤去しました。
- 一枚は記録と閲覧を切り替え、会話は履歴の下に入力を保ち、日めくりは選んだ一日だけを読み、入力はシートで開きます。以前の時間軸・片手入力は「以前の試験案」から選べます。いずれも同じ下書き・保存処理を共有します。
- 体調とメモの間の区切り線を省き、「タグ・日時」と送信を同じ行に配置します。新しい配置は `lib/layouts.ts` の定義、`record-layout.tsx` の表示、`experiments.css` のスタイルを中心に追加できます。
- 右上のパレットから「夜」「紙」「墨」の3スキンを選べます。スキンはこのブラウザーの設定です。
- CSVには投稿・総括の種別と日時を分け、タグを `名前 ×数量` の形式で出力します。

## タグと数量

- タグは必ず一つのグループに所属します。グループの追加・改名・削除、タグの追加・所属変更ができます。グループを削除するとタグは「未分類」に移ります。
- 「よく使うタグ」は全期間のタグ付き投稿回数から上位6件を自動表示します。数量の合計ではありません。同率は名前順。元のグループにも同じタグが表示され、タグ自体は複製されません。
- 入力の通常表示は「よく使うタグ」（投稿回数順、最大6件、一枚・会話では3件）のみ。最近使ったタグは表示しません。利用履歴がない場合は初期候補を表示します。
- 上の「タグ・日時」と「タグ・日時を閉じる」は同じボタン・同じ位置で切り替わります。表示ラベルは「タグ・日時」のまま、矢印と読み上げ用ラベルを切り替えます。その下だけが展開し、頻出タグの折り返しや位置は開閉で変えません。展開中だけ下側に閉じるための小さな矢印を置き、下から閉じたときは上のボタンへフォーカスと表示位置を戻します。下書き・選択タグ・数量・日時は開閉で保持します。
- タグを押すと入力欄の下に今回のタグ一覧が溜まります。各行の−・＋、または数値の直接入力で調整し、送信で確定します。その投稿にだけ数値を指定できます。すべてのタグで任意、初期値は毎回1、小数にも対応します。タグ定義に数量入力の有無を設定する操作はありません。旧定義の数量・単位フィールドは互換性のため保持しますが、入力UIには影響しません。
- 数量は履歴・編集・CSVに反映します。履歴はタグ形のチップにし、右側に1を含む数量を表示します。既存の数量なし記録も1として読みます。現在の体調との関連集計はタグの有無による比較です。
- タグの非表示は過去の記録を消しません。管理画面から再表示できます。既存タグの名前は過去記録と共通なので、別名は新しいタグとして追加します。
- 同時編集は版番号で検出し、古い管理画面からの上書きを拒否します。

## 長期間の試用データと波グラフ

- 「デザイン実験」→「ダミーデータで試す」で、120日分の架空の記録を開けます。各記録の体調・メモ・数量、日別総括、未記録日を含みます。投稿は1日2〜56件、計2,510件。朝・昼・夕・夜にまとまる短い間隔と、数時間の空白を含みます。
- 試用データは利用者ごとの別領域です。自由に追加・編集でき、「自分の記録へ」で戻れます。初回だけ生成し、再度開いても複製しません。今回の密度を増やした試用データは新しい専用領域に用意します（実記録は変更しません）。画面の再読み込みなしで、一覧と集計が揃ってから切り替えます。切り替えると入力中の下書きは閉じます。
- カレンダーの色の説明は小さな「見方」ボタンに集約。簡易統計の下に、上が緑・下が赤の日別の波グラフを表示します。総括と投稿平均を切り替えられ、未記録日の線はつなぎません。
- 統計タブの波グラフは選択した7日・30日・90日・全期間に連動。点の選択と日別数値の表で集計内容を確認できます。
- 投稿は体調未選択でも3として表示・平均集計します。投稿そのものがない日は未記録のままです。
- Apple風は専用スタイルに再構成。黒系の地、大きな見出し、日ごとの連続した記録面と、半透明・背景ぼかし・縁の反射を持つ浮いた操作部を分離します。カレンダー・統計・タグ管理・入力シートにも同じ階層を適用。紙では明るい素材、墨では無彩色寄りの素材になります。Web上の表現であり、AppleのネイティブLiquid Glass描画そのものではありません。透明度・コントラストのOS設定にも対応します。

## 保存と集計

投稿・総括・タグ管理はCloudflare D1に保存します。端末のローカルストレージはスキン・UI・試験レイアウトの設定に使用します。所有者専用のSitesアクセス設定に加え、各APIで認証済み利用者のIDによってデータを分離します。公開リポジトリには利用者の記録や資格情報を含めません。

統計の冒頭は「発見の受信箱」。古い期間から最大2件の候補を選び、新しい期間で傾向が続くか示します。下のテーマ選択からタグの前後、条件、回復まで、安定度、順序と連続、似た日の続きを調べられます。従来の日単位・タグ同士の比較は折りたたみ欄にあります。30・90・180日・全期間を選択でき、日単位の分析では総括と投稿の日平均を分けます。時刻を使う分析は投稿の体調を使用します。

- 時間差は翌日・2・3・7日後の「後日 − 当日」。当日の体調を四捨五入した1〜5の区分で比較相手をそろえ、タグあり側の日数構成でタグなし側を重み付けします。両群5日以上で差を表示。比較に使えない日数も表示します。
- 過去の後日の平均、変化量の四分位範囲、0.5点以上上向いた日数を併記。予測区間・改善確率・因果効果と混同しません。
- タグ同士は日単位のφ相関、同時出現日数と割合、両方・片方・どちらもない日の体調を表示。相関は各タグのあり・なしがそれぞれ5日以上、区分の体調平均は3日以上で表示します。
- 未記録を0や3で補わず、タグの有無は投稿がある日だけで判断。投稿が多い日も1日分として扱います。指定した後日の欠測は近い日で代用しません。
- 数量・強度、曜日、他タグ、連続使用の影響は調整していません。日単位の時間差分析であり、時間単位の薬効推定や未来予測モデルではありません。

疼痛の直接入力・表示・集計はありません。既存データを消さないため旧`pain`列のみ残し、編集でも値を変更しません。体調・タグなどから疼痛スコアを算出する機能は未実装です。詳細は[TODO](docs/TODO.md)を参照してください。

## 開発

Node.js 24、pnpm 11.25.0。`pnpm-lock.yaml`を使用します。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

通常環境は`pnpm dev`。Sitesの管理プレビューを使用する場合はSitesスキルで実行プロファイルを選択します。プレビュー用IDは開発ビルドだけに存在します。

| 場所 | 責務 |
| --- | --- |
| `app/journal.tsx` | 投稿フォーム、編集、スキン、画面の統合 |
| `components/journal/` | 共通入力・履歴・カレンダー・傾向 |
| `app/globals.css` | スキン別のデザイントークンとレイアウト |
| `lib/journal.ts` | 入力検証、型、集計、CSV |
| `lib/store.ts` | 時刻を保持する更新、ページング、総括の保存 |
| `app/api/` | 利用者認証、入力検証、DB操作 |
| `db/schema.ts`, `drizzle/` | スキーマと追記型のマイグレーション |

新しいスキンはCSS変数を中心に追加でき、保存処理から独立しています。既存のマイグレーションは書き換えず、新しいSQLを追加します。

公開方法とVercelへの移行条件は[配備メモ](docs/deployment.md)、確認結果は[検証記録](docs/validation-v16.md)を参照してください。

- 記録の日付指定は履歴見出しのカレンダーアイコンから行います。検索・タグ・「今日／全期間」は絞り込みボタンを開いた時だけ表示されます。カレンダーで選んだ日付は日めくり・時間軸にも引き継ぎます。

試験機能の計算範囲と今後の候補は[統計のアイデア](docs/statistics-ideas.md)に整理しています。発見の表示は探索用で、予測や因果関係の確定を意味しません。
