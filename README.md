# self-track-v5 — しずく

体調を少ない操作で残し、その時々の変化と一日全体を分けて振り返る個人用アプリ。

[アプリを開く](https://shizuku-health-journal.tau-s.chatgpt.site)

## 記録の使い分け

| 画面 | 記録するもの | 操作 |
| --- | --- | --- |
| その時の記録 | その瞬間の5段階の体調、タグ、メモ | 体調を選択 → 送信。タグを付けても基本3タップ |
| カレンダー | 一日全体の5段階の総括、コメント | 日付を選択 → 評価 → 総括を保存 |
| 傾向 | 一日の総括と、その時の体調の日平均を区別した集計 | 期間や分析対象を切り替えて比較 |

- 体調の選択だけでは保存しません。送信または保存ボタンで確定します。
- 投稿の編集では記録日時と日付を変更しません。更新日時だけを別に保存します。
- 過去への新規投稿は「タグ・日時」から日時を指定できます。時刻を含め日本時間です。
- 履歴は記録画面に統合。40件ずつの自動追加読み込みと、言葉・タグ・日付による検索を利用できます。
- 一日の総括は日付ごとに1件。投稿の平均から自動作成・上書きしません。
- 右上のパレットから「夜」「紙」「墨」の3スキンを選べます。スキンはこのブラウザーの設定です。
- CSVには投稿・総括の種別と日時を分けて出力します。

## 保存と集計

投稿と総括はCloudflare D1に保存します。端末のローカルストレージはスキン設定にだけ使用します。所有者専用のSitesアクセス設定に加え、各APIで認証済み利用者のIDによってデータを分離します。公開リポジトリには利用者の記録や資格情報を含めません。

タグの関連は、タグがある日とない日の体調差です。分析対象を「一日の総括」「その時の体調（日平均）」から選べます。両群3日以上で表示し、未記録を0で補わず、翌日の変化は連続する暦日だけを比較します。投稿がない日はタグの有無を観測できないので当日の比較から除きます。因果推論ではありません。

疼痛の直接入力・表示・集計はありません。既存データを消さないため旧`pain`列のみ残し、編集でも値を変更しません。体調・タグなどから疼痛スコアを算出する機能は未実装です。詳細は[TODO](docs/TODO.md)を参照してください。

## 開発

Node.js 24、pnpm 11.25.0。`pnpm-lock.yaml`を使用します。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

通常環境は`pnpm dev`。Sitesの管理プレビューを使用する場合はSitesスキルで実行プロファイルを選択します。プレビュー用IDは開発ビルドだけに存在します。

| 場所 | 責務 |
| --- | --- |
| `app/journal.tsx` | 投稿フォーム、編集、スキン、画面の統合 |
| `components/journal/` | 共通入力・履歴・カレンダー・傾向 |
| `app/globals.css` | スキン別のデザイントークンとレイアウト |
| `lib/journal.ts` | 入力検証、型、集計、CSV |
| `lib/store.ts` | 時刻を保持する更新、ページング、総括の保存 |
| `app/api/` | 利用者認証、入力検証、DB操作 |
| `db/schema.ts`, `drizzle/` | スキーマと追記型のマイグレーション |

新しいスキンはCSS変数を中心に追加でき、保存処理から独立しています。既存のマイグレーションは書き換えず、新しいSQLを追加します。

公開方法とVercelへの移行条件は[配備メモ](docs/deployment.md)、確認結果は[検証記録](docs/validation-v5.md)を参照してください。
